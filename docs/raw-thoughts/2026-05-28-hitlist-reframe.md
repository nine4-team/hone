-Inputs:
	-Training volume
	-Training quality
-Improvement = training time x training volume
-breaking this down further, it means: 
	-picking a set of skills you want to improve
	-focusing on one or two skills per session
	-sustaining that focus over time
	-them ore frequently you train per week, the faster you improve

How do we measure improvement?
-Hitting moves.

So this app has two parts: 
-tools to support inputs to the equation: deliberate practice, volume
-tools to increase the single metric that matters for measuring improvement: hits
